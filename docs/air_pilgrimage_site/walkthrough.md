# AIR 聖地巡礼コンプリートガイド ＆ フレキシブルシステム 成果確認 (Walkthrough)

Keyの不朽的名作『AIR』を心から愛するファンのための、現代最高峰のUIデザインと熱量に満ちた聖地巡礼ポータルサイトです。

GitHubリポジトリ：[https://github.com/konbu-hub/AIR](https://github.com/konbu-hub/AIR)

---

## 🗺️ 全国の全6大AIR聖地エリアの完全調査・網羅 ＆ ダイナミックシミュレーション

1. **【和歌山エリア [主舞台]】 (御坊市・美浜町・由良町)**:
   - 西御坊駅水路線路橋、浜の瀬バス停、武田商店、吉原の道と錆びたフェンス、煙樹ヶ浜、逢宕神社、白崎海岸。
2. **【兵庫エリア [旅立ち]】 (美方郡香美町 - JR余部鉄橋 / 空の駅)**:
   - OP『鳥の詩』往人が人形を抱えて旅する高さ41メートルの赤色トレッスル鉄橋。
3. **【神奈川エリア [出会い]】 (小田原市・国府津海岸 ＆ 国府津駅)**:
   - 原作DREAM編プロローグ。海が見える歩道橋とホームで観鈴と往人が出会った始まりの場所。
4. **【四国香川エリア [流浪]】 (琴平町 参道商店街 / 高松港)**:
   - アニメ第1話。腹ペコの往人が法術の人形劇の投げ銭を募るレトロなアーケード商店街。
5. **【福井エリア [神話]】 (小浜市・若狭高浜海岸)**:
   - SUMMER編 1000年前の神話。柳也と裏葉、神奈備命(神奈)が追手から逃れ歩んだ北陸の旧街道。
6. **【京都エリア [制作の地]】 (宇治市・宇治川周辺 - 京都アニメーション)**:
   - 京アニ制作陣（石原立也監督ら）が背景美術の青空、入道雲、光の描写をロケハンした地。
